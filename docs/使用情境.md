# Gama Meeting Room 使用情境

## 專案層使用情境（使用者確認 2026-10-07）

1. 誰在用：既有公司同事使用會議室預約系統。
2. 在哪用：桌機與手機瀏覽器；正式站透過 GitHub Pages 提供。
4. 階段與壽命：正式站持續提供週表、預約與「我的行事曆」功能。
5. 資料份量：預約正本在 Supabase `bookings`；政府節日可從 TaiwanCalendar 年度 JSON 重抓，自訂節日在 `index.html`。
6. 錯了的代價：重複預約、預約資料遺失或毀損會影響同事使用會議室。
7. 外部依賴：節日 CDN 失敗時不阻擋預約與會議顯示；Supabase 無法連線時顯示連線錯誤，不假裝預約成功。
8. 要防誰：沿用現有存取控制，本功能不改權限。
9. 全站必驗：預約時段防撞、預約資料正確載入與顯示；「我的行事曆」月／週／日節日顯示、跨年份、中英文切換、CDN 失敗時會議仍可見可操作。
10. 全站不驗：沒有使用者指定的不驗項。

## 已完成功能

### 我的行事曆顯示節日（完成 2026-10-07）

主要流程（使用者確認 2026-10-07）：
1. 月檢視在日期格顯示節日名稱。
2. 週檢視在日期欄頭顯示節日名稱。
3. 日檢視在當日標題顯示節日名稱。
4. 顯示既有台灣政府節日與其他自訂節日；不受「只看我的／全部」影響，節日僅供辨識日期、不限制預約。
5. 政府節日 CDN 載入失敗時，會議仍正常顯示與操作，只是不顯示政府節日；已停用的自訂節日不再出現在週表、今日節日、倒數與我的行事曆。

功能 5 行（使用者確認 2026-10-07）：
1 對象與防護：既有公司同事在桌機／手機瀏覽器使用；不改既有存取控制。
2 風險類＝：不得造成重複預約或 Supabase bookings 資料遺失／毀損。
3 必驗：月／週／日、跨年份、中英文切換、已停用的自訂節日不再出現、CDN 失敗時會議仍可見可操作。
4 不驗：無使用者指定的不驗項。
5 外部出狀況：節日 CDN 失敗時不阻擋預約與會議顯示。
